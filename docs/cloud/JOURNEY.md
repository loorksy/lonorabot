# Lonora Cloud — the customer journey, end to end

**Status: Adopted with the plan (VISION.md Amendment 3, 2026-11-22).** Each step names what the customer sees, what happens behind it, and where the
plan specifies it. Product decisions it reflects: MetaTrader only (VISION Amendment 2), the company's MetaApi account
(D27), the native Android app as the product and the website for the account only (D36–D39).

**ما لا يفعله العميل أبداً:** فتح حساب MetaApi، نسخ أي توكن، الدفع داخل التطبيق، إعطاء الشركة كلمة مروره، استخدام
تطبيق الويب بعد اكتمال المرحلة M (D37).

**أصعب خطوة:** مفتاح نموذج الذكاء الاصطناعي (الخطوة 7)، لأنه على العميل اليوم (D6). العلاج: أدلة مصوّرة بالعربي،
ومساعد الدعم، ومتابعة في الأسبوع الأول، ودليل لكل مزوّد مدعوم (OpenAI وAnthropic وDeepSeek وZ.ai وOpenRouter) يشرح
فتح الحساب وإنشاء المفتاح. الشركة لا تدفع ثمن النماذج: العميل يضع حساب مزوّده بنفسه (D6، D41 مؤكدان).

## What staff see along the way

| Moment | Staff side | Reference |
|---|---|---|
| Provisioning fails three times | Internal ticket; the customer sees "we are finishing your setup by hand" | PLAN §4.1, P3-T6 |
| A support ticket | Instance health beside the ticket, never content; diagnostics only with consent | PLAN §8, P5-T7 |
| A refund above an agent's limit, a restore, a deletion, a break-glass request | Supervisors' approvals inbox | PLAN §7.4, §7.6, P5-T8 |
| An abuse signal from a workspace | Trust & Safety case; notify → throttle → stop the workspace only | PLAN §13.8, P7-T2 |
| A release | Rings inside customers' windows, automatic halt | PLAN §13.3, P6-T5 |
