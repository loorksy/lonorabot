## L1. The bare word "Unknown" refuses ordinary agent cards
**Where:** `packages/agent-runtime/src/lonora_agent/genui_compile.py:108-109`. `FIXED_LABELS` now holds the bare words "Unknown" / «غير معروفة». They are checked for:
- headings: Title, Badge, a node's label props and Choice options;
- every separated segment of a heading.

So any agent card showing an unknown value as a label is refused as an imitation of a fixed card (10.2.2).

**Probe at the head:**

| Text | Refused as a heading | Refused as a button |
| --- | --- | --- |
| `Unknown` | yes | yes |
| `غير معروفة` | yes | yes |
| `Result: Unknown` | yes | no |
| `الحالة: غير معروفة` | yes | no |

Examples refused:
- a Badge «غير معروفة» on a news item whose effect is not yet known;
- a Title "Trend · Unknown".

Before this commit, the full phrase "Unknown: release the hold" was needed. Nothing about such a card passes for the Settle card, so this refusal guards nothing.

**Fix:** keep the Settle card's button words only where a control could imitate it:
- move "Unknown" / «غير معروفة» to a `FIXED_CONTROL_LABELS` tuple;
- check that tuple only in the `control=True` branch of `imitates_fixed_card`;
- extend `test_genui_slots.py:313`'s parity loop to cover it;
- add one case in which a Badge «غير معروفة» compiles.
