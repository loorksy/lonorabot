## Findings

### L1 (low): the "Detailed agent status" off-text is narrower than what the code shows
- Where:
  - `apps/mobile/components/agent-live-status.tsx:21` (docstring: "off, only a problem shows")
  - `apps/mobile/lib/i18n.ts:454-457` (`prefAgentStatusSub`: «عند الإيقاف يظهر للمشكلات وما يحتاج قرارك فقط» / "When off, only problems and what needs you")
- Evidence:
  - With the switch off, the strip still shows for any running watch, task or runtime wait. Lines 31-39 compute `actionable = watches.length > 0 || tasks.length > 0 || runtime_waits.length > 0 || …` and return null only if `!detailed && !attention && !error && !actionable`.
  - A running watch or task is neither a problem nor a decision waiting for the owner. So an agent with a standing task (for example the Full-mode account-management task) always shows the strip, and the switch appears to do nothing.
  - The code comment at lines 29-30 already says "anything the owner can act on (a watch, a task, …)". The owner-facing text and the docstring do not.
- Fix: make the words true. Either:
  - change the sub text to «عند الإيقاف يظهر للمشكلات وما يحتاجك وما يعمل من مراقبات ومهام» / "When off, only problems, what needs you, and running watches and tasks", and the docstring to match; or
  - drop `watches`, `tasks` and `runtime_waits` from `actionable`.

### L2 (low): the spec's header claims coverage it does not have
- Where: `tests/mobile/chat-prefs.spec.mjs:1-2`: "the conversation honours them (here: @ suggestions and the agent's activity line)".
- Evidence:
  - The spec asserts the @ suggestions, the stored `assist` value and the presence of the steps row (line 57). Nothing in it checks `agent-live-state` or the activity strip.
  - The new default (`agentStatus` false) hides the strip for an idle agent, which used to always show it. No test covers that behaviour change.
- Fix: add an assertion that `agent-live-state` is absent for an idle agent by default and present after the switch is turned on. Otherwise, drop "and the agent's activity line" from the comment.
