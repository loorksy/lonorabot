## Verified findings

### M1 (medium): the web client and the test button do not know the new provider `openai_compatible` (14.1.4, 17)
- `GET /providers` (`apps/api/src/lonora_api/routes/providers.py:24`, `for provider in PROVIDERS`) now returns `openai_compatible`, because `lonora_providers/registry.py` adds it. The web client was not updated with the API:
  - `apps/web/src/shell/settings/ConnectionPages.tsx:551-558`: `PROVIDER_NAMES` has no `openai_compatible`, so `providerName()` falls back to the raw id. The "Add a provider" `<select>` (around line 662) and the configured row (line 578) show the string `openai_compatible` to the owner (17: no raw ids, Arabic first).
  - `ConnectionPages.tsx:605`: `ProviderFormPage` returns `<NotFoundPage />` for an id missing from `PROVIDER_NAMES`. Once the deployment sets `LONORA_OPENAI_COMPATIBLE_BASE_URL` and a key, tapping the endpoint's row opens a 404.
  - `apps/web/src/lib/model_catalog.ts:2`: the `providers` list was not extended, although `packages/contracts/src/models.ts` was.
  - `apps/api/src/lonora_api/routes/connection_tests.py:47`: `model_adapter(provider, body.api_key)` passes no base URL. "Test connection" for `openai_compatible` therefore always answers `model_not_configured` 409, even when the deployment URL is set. A probe confirmed `model_adapter('openai_compatible','k')` raises `model_not_configured`.
- Fix:
  - Add `openai_compatible` to `PROVIDER_NAMES` with a translated label (for example `t\`OpenAI-compatible endpoint\``, with its Arabic entry «نقطة متوافقة مع OpenAI» in the catalog), and to `model_catalog.ts` `providers`.
  - In `dry_run_provider`, pass the configured endpoint (`await ProviderCredentials(...).endpoint(provider)`) to `model_adapter`, or answer with a clear Arabic message that the base URL is set in the deployment.

## Rejected (one line each)
- SSRF through the base URL: only the deployment env (`LONORA_OPENAI_COMPATIBLE_BASE_URL`) sets it. No route, tool or card writes it, so neither an agent nor a model can redirect the key.
- Key sent on a redirect: `BaseModelAdapter` uses `follow_redirects=False`.
- `.env.example` "your own machine" wording under Compose: an optional clarification, not untrue enough to report.
- One-label hosts trusted for plain http: the owner sets this at deploy time.
