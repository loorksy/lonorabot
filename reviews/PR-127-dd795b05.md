## Verified findings

### M1 (medium): `FIXED_WHOLE = ("Full", "Ask")` makes ordinary trading cards fall back (10.1.2 clay)
- **Where:** `packages/agent-runtime/src/lonora_agent/genui_compile.py:104`, used in `imitates_fixed_card` (`plain in WHOLE_PLAIN`). It is new in this PR (absent at 3c49ed8e and on main).
- **Probe** at the head, `imitation({'title':'XAUUSD'}, blocks, [{}], None, None)`:
  - a Grid of Stats `Bid` / `Ask`: **True** (card refused as `card_fallback_imitation`);
  - the same with `Bid` / `Spread`: False.
  - `imitates_fixed_card('Ask')` and `('Full')`: True.
- **Why it matters:** "Ask" is the standard quote label, and "Full" is a normal option (for example a close size). 10.2.2 requires only that the trust frame cannot be imitated; the frame mark and shield icon already ensure that.
- **Fix:** drop `FIXED_WHOLE`, or apply it only to the card head title and Button labels, never Stat or option labels. Add a test that a Bid/Ask quote card compiles.

### M2 (medium): merged into main e27c2357, the migration chain has two heads
- **The tree:** in `git merge-tree origin/main origin/slots/2-mandate` (no textual conflict):
  - `packages/db/migrations/versions/0060_agent_trading_mode.py` has `down_revision = "0068_end_trading_goals"`;
  - main's `0085_opportunity_pending_operations.py` has the same `down_revision`.
- **Cause:** the stale W-AUTH tip 85cf9088. W-AUTH's current chain re-parents 0060 onto 0085.
- **Fix:** re-merge the current `wauth/2-mandate-card` (or rebase onto main once W-AUTH lands), then run the migrations and `tests/check_trading_mode.py` on a fresh DB.
