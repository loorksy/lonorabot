## Finding 1 (low, 5.3.3 / 3.3.4): on a netting account, an agent that adds to the owner's position is shown as its opener

- File: `packages/trading/src/lonora_trading/morning_brief.py:309-348`. `ticket_openers` keys every agent entry by `details.position_id`, which for a netting add is the existing position's id (`verification.py:50`). It skips owner entries, and the newest entry wins.
- Probe (re-run by me): an agent buy on the owner's untagged EURUSD position p2 gives `opened_by {… 'EURUSD': 'Gold…'}`, where 3.3.4 ("from flat") makes it the owner's. On main before this PR it showed as owner.
- Fix: credit the earliest journaled entry for a ticket (owner entries included). Prefer the broker op tag, and use `position_id` only for an entry that opened the position from flat.
