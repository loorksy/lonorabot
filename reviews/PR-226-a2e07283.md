### L1 (low, parity): no "web search is on" marker in the mobile composer
- Evidence:

- Fix: add the same indicator next to "+" in `thread-composer.tsx`, with Arabic, and assert it in `composer-calls.spec.mjs`.

### L2 (low, parity): the suggestion hides only for v2 interface parts
- Where: `apps/mobile/app/thread.tsx:973`, `!(lastAgent.rich_content?.parts ?? []).some(isUiPart)`
- Evidence: `isUiPart` (core genui) matches v2 documents only. Web hides the suggestion for any part of `type === "ui"` (`GenUiPart.tsx` `hasGenUi`). So a stored older ui message with `suggested_reply` would still show the chip on mobile.
- Fix: use `.some((part) => part.type === "ui")`.
